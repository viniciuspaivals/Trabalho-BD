# Banco-De-Dados

Para utilizar o banco de dados POSTGRESQL segue-se os seguintes passos:
1. Com o DBEAVER funcionando corretamente estabeleça a conexão POSTGRESQL;
2. Execute primeiro o ficheiro localizado em `scripts/01_ddl_criacao.sql` para gerar as tabelas;
3. Em seguida, execute o ficheiro `scripts/02_dml_povoamento.sql` para inserir os dados de teste e criar o ecossistema de voos.
